# SISTEM INFORMASI TIRAS DAN TRANSAKSI BAHAN AJAR (SITTA V2)

Sistem informasi berbasis web untuk simulasi pengelolaan stok bahan ajar, tracking Delivery Order (DO), dan proses transaksi distribusi bahan ajar berbasis Vue.js.

---

## 🚀 Live Demo

🔗 https://simplepahrul.github.io/sitta-v2  

---

## 📌 Deskripsi Sistem

SITTA V2 (Sistem Informasi Tiras dan Transaksi Bahan Ajar versi 2) merupakan pengembangan dari SITTA sebelumnya dengan penambahan fitur berbasis framework Vue.js.

Sistem ini digunakan untuk mengelola:
- Data stok bahan ajar
- Monitoring status ketersediaan stok
- Tracking delivery order (DO)
- Simulasi transaksi dan distribusi bahan ajar

SITTA V2 dirancang untuk memberikan pengalaman pengelolaan data yang lebih dinamis, interaktif, dan responsif.

---

## 🎯 Tujuan Pengembangan

- Meningkatkan interaktivitas sistem menggunakan Vue.js  
- Mengelola data stok secara dinamis (CRUD sederhana)  
- Menyediakan fitur tracking pengiriman berbasis DO  
- Menerapkan konsep reactive data binding pada frontend  
- Melatih implementasi filter, sorting, dan computed data  

---

## ⚙️ Fitur Utama

### 📚 Manajemen Stok Bahan Ajar
- Tambah, edit, dan kelola data stok
- Validasi sederhana pada form input
- Status stok otomatis (Aman / Menipis / Kosong)
- Sistem reorder berdasarkan safety stock
- Filter & sorting data stok

### 🚚 Tracking Delivery Order (DO)
- Generate nomor DO otomatis (DO2025-0001, dst)
- Input data pengiriman (NIM, nama, ekspedisi, paket)
- Pemilihan paket bahan ajar
- Perhitungan total harga otomatis
- Riwayat tracking pengiriman

### 🌙 UI & UX Enhancement
- Dark mode & light mode toggle
- Interface responsif menggunakan Bootstrap
- Tampilan tabel dinamis & interaktif

---

## 🧱 Teknologi yang Digunakan

- HTML → Struktur halaman
- CSS → Styling dan UI
- Bootstrap 5 → Komponen UI
- JavaScript → Logika aplikasi
- Vue.js → Reactive frontend framework

---

## 🧠 Konsep yang Diimplementasikan

- Data Binding (v-model, v-bind)
- List Rendering (v-for)
- Conditional Rendering (v-if, v-else)
- Computed Properties
- Watchers (monitor perubahan data)
- Component-free Vue structure (single-page logic)
- LocalStorage (dark mode persistence)

---

## 📊 Manfaat Sistem

- Mempermudah simulasi manajemen stok bahan ajar
- Memberikan gambaran sistem tracking distribusi barang
- Melatih implementasi Vue.js dalam studi kasus nyata
- Menjadi dasar pengembangan sistem informasi yang lebih kompleks

---

## 🧠 Catatan Pengembangan

SITTA V2 dikembangkan sebagai lanjutan dari SITTA 1 dengan fokus pada peningkatan interaktivitas menggunakan Vue.js tanpa framework tambahan.

Sistem ini tetap dibuat sederhana agar mudah dipahami, tetapi sudah mencakup konsep inti frontend modern.

---

## 👨‍🎓 Penutup

SITTA V2 diharapkan menjadi representasi pengembangan sistem informasi berbasis web yang lebih interaktif, modern, dan siap untuk dikembangkan lebih lanjut ke tahap backend dan database.
